# Portfólio — Luiz Felipe Nascimento Mota

Portfólio pessoal construído do zero com **HTML, CSS e JavaScript vanilla** — sem frameworks, sem bibliotecas.

🔗 **[Ver ao vivo](https://luizfelipenm.dev)**

## Páginas

| Página | Descrição |
|---|---|
| `index.html` | Página principal: sobre, skills, experiências, certificados e contato |
| `projetos.html` | Vitrine dos projetos no ar: ZIULPORT, ZIULBOT, ZIULFIT e Forziul |
| `terminal.html` | Terminal interativo — explore o portfólio por linha de comando |
| `speedtyping.html` | Mini-game de digitação rápida com termos reais de TI |
| `python.html` | A cobrinha dev 🐍 — corrija bugs sem quebrar em produção |

## Estrutura

```
├── index.html
├── projetos.html
├── terminal.html
├── speedtyping.html
├── python.html
├── assets/
│   ├── css/        # um arquivo de estilo por página
│   ├── js/         # um script por página
│   ├── img/        # imagens, ícones e OG images
│   └── curriculo-luiz-felipe.pdf
├── sitemap.xml
├── robots.txt
└── README.md
```

## Destaques

- 🎨 Identidade visual dark tech com paleta neon (ciano/verde)
- 🎮 Menu "Mini Games" com dropdown reunindo Speed Typing e Python Snake
- 🗂️ Página de projetos com preview dos sites que mantenho no ar
- 🖥️ Terminal fake com histórico (↑/↓), autocomplete (Tab) e easter eggs
- ⌨️ Speed Typing com modos de tempo, WPM, precisão e ranking local
- 🟢 Seção "Agora" no hero, mostrando em qual projeto estou focado no momento
- 📱 Totalmente responsivo, pensado para mobile
- ⚡ Zero dependências — carrega instantaneamente

## Executar localmente

Basta clonar e abrir o `index.html` no navegador:

```bash
git clone https://github.com/luizfelipenm/portifolio.git
cd portifolio
```
